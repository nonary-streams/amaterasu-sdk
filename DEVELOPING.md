# Building and consuming the SDK

Run `cargo test --workspace --locked --offline` after dependencies are cached.
The committed lockfile records this source tree's validated dependency
resolution. Rust 1.89 or newer and the platform toolchain are required.

An independent extension repository may depend on an exact, reviewed SDK Git
commit and commit its own lockfile. Match the ABI major, negotiated minor and
table size at binding time. Implement `ManagedModule`, export
`amaterasu_module_v1`, and register only versioned services granted by the
verified host package. Do not create a second grant or configuration registry.
CPU frame processors receive borrowed input and return an explicitly owned
replacement; GPU/zero-copy transforms are not supported by this contract.
Observers receive metadata and must not block capture or retain frame buffers.

The host verifies signatures, approved publishers, component dependencies and
effective grants before loading native code. A signed extension still runs as
trusted in-process code. Publication of a source repository does not grant an
extension runtime access. Additive development composition and option schemas
are source-tested; production add-on activation and live devices remain
unqualified. Repository URLs, a public source license and release tags must
be finalized before a public build claim.
