# Amaterasu SDK foundation (local source proof)

Extracted from Amaterasu commit `a6b0db9e36a1a59328ab4b4785b27b210f8182b7`. This local repository contains the
existing version 1 C ABI, broker control contracts, native module SDK, and media
interface tables. It is a source compatibility proof, not an approved release.

The package versions are `0.1.0`; ABI compatibility must still be checked by
`AbiHeader` major/minor/size and each native interface version. Git tags and
package publication are deferred until repository ownership and visibility are
confirmed. Native modules remain trusted code; grants are not a sandbox.
